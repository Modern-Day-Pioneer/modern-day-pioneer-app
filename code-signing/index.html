Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Signing starts once SignPath Foundation accepts the project. Until then, releases are unsigned, and Windows asks you to confirm before installing (see Installing).

What is signed

Only the Modern Day Pioneer app and its Windows installer. Both are built from the public source code by the Windows release workflow on GitHub, so each release can be traced to the code it came from. The installer also carries FFmpeg and PDFium, which come unchanged from their own projects and are not signed by us.

Team roles

  • Authors: Jared Dickson. Code is written with the help of an AI coding assistant, and every change comes in as a pull request.
  • Reviewers: Jared Dickson reviews every pull request, including all outside contributions, before it is merged.
  • Approvers: Jared Dickson approves each signing request.

Privacy

The app sends nothing about you or your family anywhere. It goes online only when you ask it to: downloading a speech model, checking for a newer version, or sending feedback. See the privacy policy.
