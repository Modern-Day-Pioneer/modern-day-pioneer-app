Download

  • Download for Windows

The download starts right away. Older versions and release notes: all versions.

What you need

  • Windows 10 or 11 (64-bit).
  • No administrator rights; the app installs just for you.
  • An internet connection only if you choose to download the speech-to-text model (about 1.5 GB; a smaller one is available in Settings).

Installing

The installing page shows each step, including what to click while the app is unsigned. In short:

  1. Click Download for Windows above. The setup file, Modern_Day_Pioneer_Setup.exe, downloads.
  2. Open the downloaded file.
  3. Windows may show a blue box that says “Windows protected your PC”. This appears because the app isn’t signed yet. Click More info, then Run anyway.
  4. Follow the installer, then open Modern Day Pioneer from the Start menu.

Updating

Install a newer version the same way, over the old one. Your Journeys are kept. The first time the new version opens a Journey, it offers to make a backup; please say yes.

Other devices

The app is for Windows only for now. An Android version is paused.

How releases are made

Each release is built from the public source code by GitHub. See the code signing policy.
