Get help

  • Questions people ask: see the FAQ.
  • Ask a question: use the question form.
  • Send feedback from the app: Help › Send feedback (also in Settings › About). It starts an email with the app’s version filled in.
  • Something went wrong: in Settings › About, click Open the log folder and attach the newest log file to your email. It helps find the cause.
  • Installing: see Installing.
