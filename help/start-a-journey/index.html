Start a Journey

A Journey holds one family history: its people, pictures, recordings, memories and stories.

  1. Install the app (Installing) and open it.
  2. Type a name for the Journey, such as “The Rowan Family”. You can change it later.
  3. You arrive on Home. The Getting started card lists five first steps. Each one ticks itself off when you do it, and Show me opens its Help page.

The sidebar takes you to Stories & Memories, People, Waiting (pictures and recordings not yet in a memory) and Preview. Help at the foot of the sidebar opens these pages.

Change the look: in Settings, Look switches between Scrapbook (leather, wood and paper; the default) and System (plain, following Windows light and dark). Density set to Comfortable makes rows and buttons larger.

Don’t need the card? Click Hide this. Help › Show the getting-started card again brings it back.
