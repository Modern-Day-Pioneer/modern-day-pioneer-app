# towns.zip

Towns of 1,000 or more people, for naming the places in Google Takeout
locations without going online (`src/towns.rs`). One line per town:
name, region, country, latitude, longitude, separated by tabs.

Made from GeoNames (https://www.geonames.org/): `cities1000.txt`,
`admin1CodesASCII.txt` and `countryInfo.txt` from
https://download.geonames.org/export/dump/, downloaded 2026-11-02.
